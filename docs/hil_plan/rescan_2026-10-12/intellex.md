# Intellex coverage audit (2026-10-12)

Slice: every user-facing feature of Intellex (host, bridge, reconnect, transports, discovery, flashing, cache/proxy, settings, docs viewer, launcher, shell, shim, app, paths/log/certs, fetch tools, launchers). A bare `file:line` is `Intellex/src/<file>`. Tests are the harness ids in `tests/hil/suites/s32..s36_intellex*.py` (the Playwright specs and venv scripts run under them). The harness runs on macOS: Windows-only paths (netsh) are marked blocked by platform.
